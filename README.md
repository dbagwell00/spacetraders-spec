# spacetraders-spec

A language-agnostic technical specification for a high-concurrency, autonomous
[SpaceTraders.io](https://spacetraders.io) fleet client.

- [`SPEC.md`](SPEC.md) — the specification. All five sections are written:
  system architecture & data flow, entity & state definitions, process &
  workflow specs, external dependencies & I/O protocols, and the concurrency
  model. Copied from
  `~/spacetraders/erlang/.ralph/specs/spacetraders-spec/SPEC.md`.
- [`PROMPT.md`](PROMPT.md) — the ralph prompt that produced it (source:
  `~/spacetraders/erlang/PROMPT.md`, referenced as `prompt_file` in `ralph.yml`).

Both files are point-in-time copies, not live syncs.
